# Recommended GitHub Labels

Keep the initial label set small enough to use consistently.

| Label | Colour | Purpose |
| --- | --- | --- |
| `type:bug` | `d73a4a` | Defect in implemented behaviour |
| `type:feature` | `0e8a16` | New user-visible capability |
| `type:architecture` | `5319e7` | Architecture/ADR-impacting change |
| `type:documentation` | `0075ca` | Documentation-only work |
| `type:test` | `1d76db` | Test infrastructure or coverage |
| `type:refactor` | `c5def5` | Behaviour-preserving code restructuring |
| `type:chore` | `ededed` | Repository/build/maintenance work |
| `type:security` | `b60205` | Security hardening; public vulnerabilities still use private reporting |
| `area:ui` | `fbca04` | WinForms and UX |
| `area:domain` | `bfdadc` | Domain model and invariants |
| `area:persistence` | `c2e0c6` | SQLite/EF Core/migrations |
| `area:import-export` | `fef2c0` | Exchange formats |
| `area:backup-recovery` | `f9d0c4` | Backup, restore, crash recovery |
| `area:references` | `d4c5f9` | Repository/chat/document/link references |
| `area:build-release` | `bfd4f2` | CI, packaging and release |
| `priority:p0` | `b60205` | Release blocker / data-loss risk |
| `priority:p1` | `d93f0b` | Must be addressed in current milestone |
| `priority:p2` | `fbca04` | Normal planned priority |
| `priority:p3` | `cfd3d7` | Nice-to-have / later |
| `status:blocked` | `000000` | Cannot progress |
| `status:needs-decision` | `e99695` | Explicit product/architecture decision required |
| `status:ready` | `0e8a16` | Sufficiently defined for implementation |
| `good first issue` | `7057ff` | Only after the codebase is mature enough for external contributors |

Do not use labels to duplicate milestone information.
