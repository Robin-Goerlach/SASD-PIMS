# Architecture Documentation

The project architecture baseline has been consolidated as version 1.0 outside this starter package.

When the implementation repository is created, add the approved architecture artifacts here in a stable, versioned structure. Recommended approach:

```text
docs/architecture/
├── README.md
├── SAD/
├── ADR/
├── diagrams/
└── traceability/
```

Do not copy only the final PDF. Keep Markdown and editable diagram sources under version control so architecture changes can be reviewed as code changes.

The architecture documents describe the **target architecture**. Their existence does not prove implementation. ADR status and implementation evidence must remain distinguishable.
