# SASD PIMS 0.2.0 — Quick Start

1. Extract the ZIP to a local directory on Windows 11 x64.
2. Start `Sasd.Pims.WinForms.exe`.
3. Select a project or create one with **Neu**.
4. Use **Steuerung** for phase, activity, target date and reviews.
5. Use **Blocker** to add obstacles or retain their resolution history.
6. Select **Nur Handlungsbedarf** to focus on overdue reviews, open blockers or overdue targets.
7. Press F1 for the local glossary.

Data is stored locally under `%LOCALAPPDATA%\SASD\PIMS`. Use **Sicherung** before operationally
significant changes and **Wiederherstellen** only with a verified PIMS backup package.
