# SASD PIMS 0.2.0 — Release Notes

`0.2.0` extends the practical local project catalog with lightweight project steering.

Available functions:

- controlled, independent Project Phase and Activity State;
- optional target date with readable due indication;
- review schedule and “review completed” action with derived freshness;
- concrete attention reasons and a catalog attention filter;
- add, inspect and resolve blockers while retaining resolution history;
- archive/reactivation remains independent and reversible;
- local German F1 help and glossary;
- additive migration from the accepted 0.1 database with pre-migration backup;
- verified backup and staged restore for the expanded schema.

The JSON project exchange format remains `1.1-internal`; 0.2 steering fields are not silently added
to that versioned format. Requirements, typed references, risks, decisions, milestones, releases,
products, dashboards, cloud synchronisation and plugins remain outside this release.

Manual visual checks on physical 125%, 150% and 200% displays and the long-running endurance test
remain release acceptance activities.
