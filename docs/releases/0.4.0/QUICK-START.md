# SASD PIMS 0.4.0 — Quick Start

1. Extract the ZIP on Windows 11 x64 and start `Sasd.Pims.WinForms.exe`.
2. Press Ctrl+F or choose **Ansicht → Globale Suche** to search Projects, Requirements, Blockers and references.
3. Combine object/Project filters and use **Filter zurücksetzen** to return to the unfiltered view.
4. Select a Project and choose **Projekt → Traceability** to navigate its existing relationships.
5. Choose **Datei → Vollständiger JSON-Export** for exchange format 1.0.
6. Choose **Datei → Markdown-Projektsteckbrief** for a human-readable Project export.
7. Press F1 for the local glossary.

0.4.0 is export-only. It neither imports data nor reads, embeds or transforms referenced local files.
