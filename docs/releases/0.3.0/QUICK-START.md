# SASD PIMS 0.3.0 — Quick Start

1. Extract the ZIP on Windows 11 x64 and start `Sasd.Pims.WinForms.exe`.
2. Select or create a Project.
3. Choose **Anforderungen** or **Projekt → Anforderungen und Referenzen**.
4. Create Project references that may be shared as sources or verification references.
5. Create a Requirement; new Requirements start as **Vorgeschlagen**.
6. Add at least one acceptance criterion for every **Muss** Requirement.
7. Maintain Requirement-specific references where Project context is too broad.
8. Use **Öffnen** only after reviewing the displayed target.
9. Press F1 for the local glossary.

Data remains under `%LOCALAPPDATA%\SASD\PIMS`. Missing local targets are reported and retained.
